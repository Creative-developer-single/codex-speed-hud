# Codex Speed HUD 中文说明

本机 Codex 桌面速率插件：首流延迟、tok/s 码表、本次对话平均、累计 tok 和 API 等价费用。右上角工具栏的紫色码表按钮可随时开关面板，隐藏期间继续采集；模型、推理强度和 Fast 标识只显示上次结束输出的记录。

这是独立社区项目，工具栏按钮通过本机 UI 适配插入，并非 OpenAI 官方扩展入口。

## 安装

已验证 Linux ChatGPT/Codex 桌面发行版；需要 Node.js 22.15+ 和支持本地插件命令的 Codex CLI。macOS/Windows 未验证，暂不支持自动持久启动配置。

发布 ZIP 内已经打包运行依赖，解压后进入 `codex-speed-hud/`：

```bash
node scripts/install.mjs
```

从 Git 源码安装：

```bash
npm ci --no-audit --no-fund
npm run build
node scripts/install.mjs
```

安装器只改用户级应用菜单入口，不改系统安装文件。当前 App 没有调试端口时，正常退出再通过原应用图标打开一次；不会强制终止聊天。以后正常启动自动开启本机调试端口并启动检测器。

## 使用与指标

- 右上角码表按钮开关面板；面板可拖动，按钮留在工具栏。「−」收起内容，「×」隐藏。
- 首流：基础模式从回合开始至模型通知；原生补丁从模型请求开始至第一条解码响应事件，包含 `response.created`，不等待正文。
- 速率：正文与工具参数为最近窗口的本地估算；压缩没有明文增量时仅在结束后用原生输出 tok / 请求总耗时显示平均吞吐，保留快照。
- 本次平均：有原生补丁时，同一个用户轮次所有已完成调用的总输出 tok / 总调用耗时，包含等待、推理、工具参数、压缩；没有补丁时统计观察到的正文流。工具执行输出不计入。下一条消息重置，不混历史 Fast 模式；手动压缩拥有独立轮次。
- 累计：当前聊天历史总输入 + 总输出，缓存和推理不重复相加，显示 K/M/B 和 API 等价费用，不是订阅账单。

GPT-6.1 Sol 默认 500K 长上下文阈值是项目要求保留的覆盖配置，并非已证实的官方计费声明。用 `CODEX_SPEED_HUD_SOL_CONTEXT_THRESHOLD` 按当前价格表调整。价格每天从公开文档刷新。

## 工具与压缩采集

仅安装 HUD 不会自动启用原生补丁。默认 App 通知不含工具参数增量；若要测量工具生成速度，需要构建精确匹配的可选客户端。目前只支持 `0.162.0-alpha.17.2`，详见[原生补丁说明](native-observer.md)。App 更新后哈希保护回退原客户端，需要重新验证版本。
