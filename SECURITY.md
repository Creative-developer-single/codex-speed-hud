# Security reports

Do not post vulnerabilities containing credentials or private chat data in public issues. Use the GitHub repository's private vulnerability reporting option **if the maintainer has enabled it**; otherwise contact the repository owner through a channel they publish. No private reporting service is currently promised.

Only the current release is maintained. The native observer is version-pinned and must be audited again for any new upstream version. Loopback DevTools is local inspection access and should not be exposed outside the machine. Changes must not add model forwarding, alter authentication/transport, enable hidden timing headers, or retain plaintext in published state.
